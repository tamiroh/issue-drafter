# issue-drafter

A local-first editor for GitHub Issue drafts, with Markdown templates, previews, and automatic browser storage. Open finished drafts on GitHub to submit them.

## Use online

Open <https://tamiroh.github.io/issue-drafter/> to start drafting right away. Nothing to install, and drafts stay in your browser.

## Run locally

Use Node.js 22.12+ and npm.

```sh
npm install
npm run dev
```
